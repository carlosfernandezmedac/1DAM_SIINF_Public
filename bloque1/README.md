## ¿Qué vamos a ver en este bloque?

```
Tema 1  ──►  Las piezas          → qué hardware forma un ordenador, cómo se conecta
                                    y cómo trabajar con él de forma segura
Tema 2  ──►  El software de uso  → qué aplicaciones se usan y cómo se explotan
Tema 3  ──►  El "cerebro"        → qué es un sistema operativo y qué tipos hay
```

Primero identificamos **de qué está hecho** un ordenador (Tema 1); después vemos **qué se ejecuta encima** del hardware, primero las aplicaciones de uso general (Tema 2) y después el sistema operativo que las hace posibles (Tema 3). Es la base de todo lo que viene después: instalar, configurar y administrar sistemas operativos.
